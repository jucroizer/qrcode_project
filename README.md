# Frontend Mentor - QR Code Component Solution

This is a solution to the [QR code component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H).

## Overview

This project is a simple and polished landing page built with HTML and CSS, inspired by the QR code component challenge. The goal was to reproduce a clean card layout with a centered QR image, modern typography, and responsive spacing.
